# Cohort-1

> A collaborative MERN/web development cohort repository where each student maintains assignments, practice work, and mini-projects inside their own folder.

## Overview

`Cohort-1` is a shared learning repository for cohort members to submit, organize, and review their work in one place. It is designed to keep contributions structured, beginner-friendly, and easy to navigate for mentors, reviewers, and new contributors.

This repository is especially useful for:

- tracking student progress across assignments and practice work
- keeping each contributor's work isolated in their own directory
- showcasing beginner-to-intermediate web development projects
- giving new contributors a simple open-source workflow to follow

## Key Features

- **Per-student workspace:** every contributor has a dedicated folder
- **Beginner-friendly structure:** simple layout that is easy to browse
- **Project variety:** includes HTML, CSS, JavaScript, and React/Vite-based work
- **Contribution-ready workflow:** clear expectations around branches, commits, and pull requests
- **GSSOC-friendly onboarding:** welcoming for first-time contributors and reviewers

## Tech Stack

This repository primarily contains:

- **HTML**
- **CSS**
- **JavaScript**
- **React + Vite** (in some subprojects)

Because this is a cohort repository, setup instructions can vary slightly from folder to folder depending on the project.

## Repository Structure

```text
Cohort-1/
├── <student-name>/
│   ├── assignments, practice files, or mini-projects
│   └── README.md (optional student/project notes)
├── plsagain.html
└── README.md
```

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Max-Rex-2006/Cohort-1.git
cd Cohort-1
```

### 2. Open the folder you want to explore

Each student works inside their own directory. Choose the relevant folder and then:

- open `.html` files directly in your browser, or
- open the folder in your editor to review the source code

### 3. Run React/Vite projects if applicable

Some folders include standalone React projects with their own `package.json`.

Example workflow:

```bash
cd path/to/student/project
npm install
npm run dev
```

> There is no single root-level setup command for the entire repository because individual folders may contain different project types.

## How to Use This Repository

- Browse student folders to review assignments and project work
- Use the repository as a reference for web development practice and collaboration
- Track progress through commits and pull requests
- Review project-specific README files inside individual folders when available

## Contributing

Contributions are welcome, especially from learners and first-time open-source participants.

Please follow these guidelines:

1. **Fork** the repository
2. **Clone** your fork locally
3. Create a branch named `yourname-weekX`
4. **Work only inside your own folder**
5. Commit your changes with clear messages
6. Push your branch and open a pull request

If a root-level `CONTRIBUTING.md` is added later, please follow that document for the complete contribution workflow.

## Best Practices for Contributors

- Do not modify another student's folder unless explicitly requested
- Keep pull requests focused and easy to review
- Write descriptive commit messages
- Add or update documentation when your change affects usage
- Be respectful and collaborative during code review
